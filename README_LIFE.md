# عبدالله | إدارة الحياة — Native Android

**الحالة:** إصدار تأسيسي وظيفي قيد اختبار البناء — 0.1.1. ليس التسليم النهائي للمواصفات الشاملة.

## أين يوجد التطبيق؟
مشروع تطبيق مستقل داخل مجلد `life/`. لا يحذف تطبيق تتبّع السابق من الفرع الرئيسي.
- لغة Kotlin وJetpack Compose وMaterial 3 وRoom وCoroutines/Flow وDataStore.
- قاعدة واحدة بها 12 جدولًا تشمل الملفات والمهام والمواعيد والأنشطة والمشاريع والمتتبعات والقياسات والحالات والالتقاطات والمراجع والمراجع غير المحلولة وسجلًا خفيفًا للتغييرات.
- UUID ثابت لكل كيان، وروابط `fileId` و`projectId` و`caseId` حيث يلزم.
- 5 تبويبات: اليوم، المهام، الملفات، التقاط، المزيد.
- شاشة اليوم بتاريخ هجري وميلادي وأحداث اليوم والمهم من المهام والأنشطة.
- أوضاع عرض: طبيعي، مخفف، طوارئ، إجازة. الأوضاع لا تنسخ السجلات ولا تنشئ تراكمًا وهميًا.
- إنشاء عناصر من شاشة الملف/المشروع/الحالة مع تمرير المعرّفات تلقائيًا.
- استمرار عمل ملف/مشروع/حالة من الحالة الحالية ونقطة التوقف والخطوة التالية.
- البحث العربي المطبّع في أسماء وتفاصيل السجلات.
- التقاط النص/الرابط، وتحويل الالتقاط إلى مهمة باستخدام معاملة SQLite واحدة مع تسجيل الوجهة.
- تتبّع رقمي يدوي مع سجل توقيت.
- نسخة JSON تحتوي السجلات والعلاقات، `schemaVersion` و`backupVersion` وبصمة SHA-256.
- استعادة النسخة الخاصة بهذا التطبيق بعد التحقق منها، والمعاملة ذرية (rollback عند الفشل).
- حفظ محلي بدون تسجيل حساب أو اتصال بالإنترنت.

## غير مكتمل — لا يُعرض على أنه منفذ
- استيراد ملفات النسخ الاحتياطية للتطبيقات القديمة ذات الصيغ المختلفة.
- مرفقات الصوت والصورة والفيديو والملفات، أو نسخها احتياطيًا؛ نسخة JSON بيانات فقط.
- مركز إشعارات متقدم، تنبيهات شاشة القفل، Widgets وShortcuts وDeep Links.
- تشفير قاعدة البيانات، القفل البيومتري، وإعدادات الخصوصية المتقدمة.
- FTS مفهرس، Migration بين إصدارات مختلفة، اختبارات الأجهزة الفعلية.
- تقارير فترات مطولة، حركات سحب وإدارة أرشيف كاملة، والحذف النهائي من السلة.
- استعادة العناصر المحذوفة فرديًا أصبحت متاحة.
- تحرير جميع الحقول في كل نوع، خطط مشاريع متعددة المراحل، وميزات تكرار نشاط متقدمة.
- استعادة الإعدادات في النسخ الاحتياطية.
- وجود `Room` لا يعني أنه تم بناء وفحص Release APK موقّع.
- لا تُنقل بيانات التطبيقات السابقة تلقائيًا ولا تُمس البيانات الموجودة على الهاتف.

## البناء
يُبنى التطبيق بأمر:
```sh
gradle :life:assembleDebug
```
وتُنشئ GitHub Actions ملف `dist/abdullah-life.apk` إذا اكتمل البناء بنجاح.

التطبيق السابق `:app` يبقى مستقلًا دون تعديل كوده.


## تثبيت APK التجريبي والاحتفاظ بالبيانات
- الإصدار 0.1.1 يتضمن أيقونة تطبيق واضحة واستعادة فردية من السلة.
- يتم توقيع الحزمة حاليًا بمفتاح Android debug على بيئة GitHub Actions. هذا **ليس مفتاح تحديث ثابتًا مضمونًا** بين كل عمليات البناء؛ قد يرفض Android تثبيت إصدار جديد فوق إصدار قديم بسبب اختلاف التوقيع.
- **إذا كنت قد أدخلت بيانات فعلية في نسخة سابقة، صدّر نسخة بيانات من داخل التطبيق أولًا قبل أي حذف أو إعادة تثبيت**. ثم حمّل الإصدار الجديد واستعد البيانات منه بعد التثبيت. النسخة لا تحفظ مرفقات خارجية.
- يُستخدم للتجربة، لا لحفظ بيانات حساسة أو لا يمكن تعويضها قبل اعتماد توقيع إطلاق ثابت، اختبارات تثبيت فعلية، واستراتيجية نسخ احتياطي مكتملة.
- نسخ APK المنشورة تلقائيًا قد تحمل توقيعات اختبار مختلفة؛ قبل توفير تحديثات عادية دون إزالة التطبيق يجب اعتماد مفتاح Release ثابت محفوظ بسرية.
- التحقق الآلي يشمل `unzip -t` و`aapt dump badging` و`apksigner verify` وبصمة SHA-256؛ لكنه لا يعوض اختبار التثبيت والتشغيل على جهاز حقيقي.
